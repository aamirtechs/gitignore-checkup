How it works

  • Stack picker (Node, Python, Java, Go, Rust, PHP, Ruby, macOS, Windows, IDEs) assembles a correct .gitignore.
  • Paste your file list and audit it against the generated rules plus any existing .gitignore you paste.
  • Pattern explainer per file: which pattern matched, and on which line, including negation handling.
  • Danger flags for .env files, private keys, keystores and credential file patterns.
  • Download the .gitignore and a plain-text audit report.
